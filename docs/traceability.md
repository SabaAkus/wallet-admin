# Assignment requirement traceability

The requirement text below is transcribed from `data/Task.pdf`. “Manual check” means
the final submission rehearsal performed against a fresh disposable database.

| Exact Task.pdf requirement | Implementation evidence | Automated test | Manual verification | Assumption or limitation |
|---|---|---|---|---|
| “Stores this information in a database.” | Seven SQLAlchemy models; migrations `0001` and `0002`; historical importer | `test_migration_creates_exact_primary_tables`; historical import suite | Migrate and import the 12-row CSV; inspect transaction list | Source is an incomplete snapshot, not a reconstructable ledger |
